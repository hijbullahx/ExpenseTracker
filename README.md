# Expense Tracker
A personal expense tracking web application built with ASP.NET Core MVC, Entity Framework Core, and SQLite.
Developed by Md. Taher Bin Omar Hijbullah.

## Features
- Add and view expenses with categories (in BDT).
- Summarize expenses by category.
- About section showcasing the developer’s bio and IoT/ML projects.

## Setup
1. Clone the repo: `git clone https://github.com/hijbullahx/ExpenseTracker.git`
2. Restore NuGet packages: `dotnet restore`
3. Run migrations: `dotnet ef database update`
4. Run the app: `dotnet run`
